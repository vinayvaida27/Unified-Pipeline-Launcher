# Code of Conduct

We want this project to be a respectful, constructive place for everyone.

## Expected behavior

- Be respectful and discuss ideas in good faith.
- Give feedback about code and behavior, not people.
- Protect private, clinical, laboratory, and security-sensitive information.
- Help keep discussions welcoming and focused on the project.

## Unacceptable behavior

Harassment, discrimination, personal attacks, doxxing, sharing sensitive data,
or deliberately disruptive behavior are not acceptable.

## Reporting

Report conduct concerns privately to the repository owner. Do not include
sensitive information in public issues or discussions. Reports will be reviewed
fairly and confidentially where possible.
